**New in 0.1.2**

**Test lists without a size limit**
- `caselist.txt` files of any size load, including the full list of all 3,215,124 tests. Names this CTS doesn't have are counted and the first 200 shown. Thanks to Hugo for asking.

**Test programs at once**
- Settings › Test programs at once: run from 1 up to one test program per CPU core at the same time. On an AYANEO Pocket FIT, Rendering basics (16,300 tests) took 33 s with 8 at once against 2 min 33 s one at a time, with identical results. Test times are less comparable when several run at once, and each program needs memory. Recording always runs one at a time. Thanks to Hugo for asking.

**Game features**
- Drivers › controller icon (or Tests › ⋮ › Game features): what DXVK (Direct3D 9–11) and VKD3D-Proton (Direct3D 12) need from a driver, read from their own code (DXVK f8637768, VKD3D-Proton 8293130e), plus Shader Model 6.6 (Unreal Engine 5 games), hardware ray tracing (DXR) and mesh shaders.
- One check reads what a driver supports (extensions and feature values from the CTS info tests). Two drivers can be compared side by side; each item shows ✓, ✗ or "not reported". Each profile has a focused test set to select.
- Some requirements are device limits or properties DriverLab doesn't read; the notes say which.

**Find a setting that fixes it (Turnip)**
- On a failed or crashed test of a Turnip run, runs the test again once with the driver's own options and once per Mesa debug setting (`TU_DEBUG` sysmem, gmem, nobin, forcebin, noubwc, nolrz, nolrzfc, flushall, syncdraw, rast_order, unaligned_store, 3d_load, nocb; `IR3_SHADER_DEBUG` nouboopt, spillall, nopreamble, nofp16 — Mesa's freedreno guide list plus a few more). Shows which settings make it pass; one tap adds a setting to the driver's options.

**Results**
- Sessions under day headers, with search (driver, GPU, tests, date) and a "With problems" filter.
- A session's tests by group (collapsible, with counts, groups with failures first) or as a list; sort by problems first, name, slowest or run order; search matches names and messages. Filtering runs in the background, so big sessions stay smooth.
- Previous/next arrows on a test step through the list you were looking at.

**Fixed**
- A run no longer stops with "Run error: read interrupted" when reading a test program's output fails (seen once): that test is marked Crash with the reason and the run goes on.

**Checked on** an AYANEO Pocket FIT (Snapdragon G3 Gen 3, Adreno A33, Android 14): the full 3.2 million name list, 8 programs at once against 1 on Quick check, 1,040 atomics tests and Rendering basics (identical results and failures), Game features against the driver's raw report and side by side, the setting finder flow on Banners-Turnip r4, the Results screens, and a Quick check with recording on the final build. The read-error fix is in place but the error couldn't be made to happen on purpose.

Ideas for Game features and the setting finder came from Kimchi.

**Needs** arm64, Android 11 or newer. Signed with the public AOSP test key (v1/v2/v3); updates 0.1.1 in place.
