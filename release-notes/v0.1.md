First version of DriverLab: run the same Vulkan tests on your phone's own driver and on a custom driver (for example a Banners-Turnip zip), record what each driver sends to the GPU, and compare the results.

**What's in 0.1**
- Vulkan CTS 1.4.7.1 built for Android (3.2 million tests), with a test picker: browse groups, search, presets (Quick check, Driver info, Rendering basics, Capture set) or any single tests.
- System driver or an imported driver (AdrenoTools zip or .so), checked on import, with per-driver options such as `TU_DEBUG=sysmem`. Nothing on the phone is changed.
- Live run screen with counters, speed and time left; runs keep going with the screen off; crashed or hanging tests are recorded and the run continues.
- Optional recording of GPU commands (.rd): our own recorder for the Qualcomm driver, Mesa's FD_RD_DUMP for Turnip.
- Results per session and per test, a compare view for two sessions, and a register-by-register diff for tests recorded on both drivers.
- Files tab to read, share, copy or delete everything a run saved.
- After each run: `Download/DriverLab/<date>/` gets the full zip, a `test_results` zip in the same layout as the adreno-cmdstream-gather app, and a readable time-stamped log.

**Needs** arm64, Android 11 or newer. Built and checked on a Retroid Pocket Duo (Adreno 722).

Signed with the public AOSP test key (v1/v2/v3).
