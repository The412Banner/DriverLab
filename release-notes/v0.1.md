First version of DriverLab: run the same GPU tests on your phone's own driver and on a custom driver (for example a Banners-Turnip zip), record what each driver sends to the GPU, and compare the results.

**What's in 0.1**
- Vulkan CTS 1.4.7.1 built for Android (3.2 million tests) plus the 68 OpenGL ES test programs of the adreno-cmdstream-gather app (66 freedreno tests and two written for DriverLab: test-texturator and test-ovr-multiview).
- Test picker: browse groups, search, presets (Quick check, Driver info, Rendering basics, Capture set) or any single test. Every preset, group and test has an ⓘ button with a plain explanation.
- System driver or an imported driver (AdrenoTools zip or .so), checked on import, with per-driver options such as `TU_DEBUG=sysmem`. Nothing on the phone is changed.
- Live run screen with counters, speed and time left; runs keep going with the screen off; crashed or hanging tests are recorded and the run continues.
- Optional recording of GPU commands (.rd): DriverLab's recorder for the Qualcomm driver (with a full kernel log in the same format as the original app), Mesa's FD_RD_DUMP for Turnip.
- Results per session and per test, a compare view for two sessions, and a register-by-register diff with register names for tests recorded on both drivers.
- Files tab to read, share, copy or delete everything a run saved.
- After each run: `Download/DriverLab/<date>/` gets the full zip, a `test_results` zip in the same layout as the adreno-cmdstream-gather app (`<test>.log` + `<test>.rd`), and a readable time-stamped log. The Capture set with recording on reproduces that app's zip (its 68 GLES programs and the Vulkan tests that still exist in CTS 1.4.7.1).

**Checked on** a Retroid Pocket Duo (Adreno 722, Android 16): Quick check and Capture set on the Qualcomm driver and on Banners-Turnip 710-720-Test, recording, compare, register diff and exports.

**Needs** arm64, Android 11 or newer. Signed with the public AOSP test key (v1/v2/v3).
