**New in 0.1.1**

**Qualcomm drivers taken from other phones**
- Shared Qualcomm driver zips (AdrenoTools zips that carry their own `libgsl.so`, `libllvm-glnext.so` and so on) can now be imported and tested. Before, they showed "Could not load this driver".
- Every file in an imported zip is kept (also in subfolders). Before the driver starts, DriverLab opens the driver's own libraries from its folder; the test program keeps the phone's own system libraries.
- When a driver can't load, its card says why in plain words, for example that it was made for a newer Android. Many shared drivers need Android 15 or newer. Tap the message to see all of it. Cards also show how many files came with the driver and the Android version its package asks for.
- An imported Qualcomm driver reports the GPU's real name. Some devices present another name to apps (the AYANEO Pocket FIT shows "Adreno (TM) 750" for its Adreno A33).

**Test lists**
- Tests › ⋮ › Load test list: pick a `caselist.txt` (one test name per line, the format the Vulkan CTS uses). Whole groups as `dEQP-VK.api.*`, `#` comments and Mesa-style `name,Fail` lines work too. Names this CTS doesn't have are listed after loading.
- Tests › ⋮ › Save test list: saves the current selection as `caselist.txt`.
- On a finished run, the list button turns its failed and crashed tests (or any results you tick) into the selection for a new run, for example on another driver, or saves them as `caselist.txt`.
- Long lists of single tests no longer slow the test counter down.

**Checked on** an AYANEO Pocket FIT (Snapdragon G3 Gen 3, Adreno A33, Android 14), in the app: importing the phone's own Qualcomm driver packed like a shared zip (flat and with a subfolder) and running tests on it, the "made for a newer Android" message for a driver built for Android 15+, loading, saving and re-running test lists, and making a list from a run's results. A tester reports that the first test build loads his Qualcomm driver on a Nubia Z80 Ultra.

Thanks to Hugo for reporting the driver problem, the fix idea, and asking for test lists.

**Needs** arm64, Android 11 or newer. Signed with the public AOSP test key (v1/v2/v3); updates 0.1 in place.
