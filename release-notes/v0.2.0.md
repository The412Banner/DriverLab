**New in 0.2.0**

**A new look and a one-screen Home**
- Home is now a dashboard: driver A against driver B at the top, Conformance or Speed test, one Start button and four live tiles. Conformance shows the pass rate, tests per second, repeat runs and GPU health while tests run; the speed test shows the live picture, frame time and the score so far.
- Turn the phone sideways (or use a wide screen) and the same dashboard splits in two: setup on the left, tiles on the right. A run keeps going when you turn the phone.
- No bottom tabs any more: Tests, Results, Drivers and Settings open from the icons at the top. Files and the speed test history open from Results.
- Darker, sharper style with a blue accent, thin outlines and fixed-width numbers (JetBrains Mono).

**Speed test**
- The same small Vulkan scenes on one or two drivers: a TV-style test card, a spinning cube, filling the screen, textures, many triangles, many draw calls, keep-the-picture passes (tile memory), compute maths, memory speed and shader setup.
- Two drivers take turns each round (A then B, then B then A) with an optional cool-down pause. A driver only counts as faster when the gap is bigger than the variation between rounds and at least 3%; otherwise it says "no clear difference".
- A live picture of what the driver draws (tap for full screen) and a live frame-time line.
- Picture check: every driver draws the same test card frame, and DriverLab compares it pixel by pixel with driver A's. Differences are marked in red. A report and a side-by-side picture are saved to Download/DriverLab.

**Finding bugs**
- Run each test 1, 3, 5 or 10 times. A test whose runs give different results is marked "sometimes fails", with how many runs passed.
- GPU error check (needs root): reads the kernel log while tests run and ties GPU faults and hangs to the tests running at that moment, even when the test passed. Magisk 31.1 and newer no longer show a request prompt, so allow DriverLab in Magisk's Superuser tab first.
- Known to Mesa (Turnip): failures that Mesa's own Turnip testing also gets, or calls unreliable, are labelled, with a filter for the rest. Mesa has lists for the Adreno 618, 660, 702 and 750; other GPUs use the closest list of the same generation and the label says so.

**Comparing drivers**
- Make a copy of a driver with other settings (for example GMEM on and off) without importing it again; the copy uses no extra space.
- Driver B on the Home screen: a run goes through the same tests on both drivers, then Compare opens.

**Changed**
- An earlier "Wallpaper colours" choice is reset once so the new look shows; it can be turned on again in Settings.

**Checked on** an AYANEO Pocket FIT (Snapdragon G3 Gen 3, Adreno A33 that its driver reports as Adreno 750, Android 14) with its own Qualcomm driver and Mesa Turnip r4: the speed test with both drivers (live picture, report, picture check: all test cards matched), repeat runs, a driver copy with GMEM forced, two-driver runs with Compare, the GPU error check (Magisk allow rule, and a labelled test line written to the kernel log), the Mesa labels, the dashboard upright and sideways during a run, and the other screens.

**Not yet seen on a device:** a test that really changes result between runs, a real GPU fault, a picture check that finds a difference, and the Retroid Pocket Duo (Adreno 722).
