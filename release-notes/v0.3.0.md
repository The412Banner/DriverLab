**New in 0.3.0**

**Driver inspector**
Tap the code button on any driver in Drivers, including the device's own driver.
- **Overview:** version, build date, compiler, GPUs named in the file, size, needed libraries and exported functions.
- **Functions:** finds the functions in the driver, also the ones only reached through code pointers, and shows each one as C code (decompiled). Rename functions, add notes and edit the code; DriverLab keeps them.
- **Make source code:** turns every function of the driver into C files you can read, search and save as a zip to Download/DriverLab/inspect. This is rebuilt code, not the original source.
- **Compare** two drivers: version, GPUs, exported functions and text, and optionally the functions.
- **Text:** the readable text inside the driver.

**Names files (Turnip)**
- Banners-Turnip releases now come with a names file for each driver. With it, every function gets its real name, its exact size and the Mesa file and line it comes from, and a **Mesa source** button opens that line in Mesa's code. Decompiled code then shows the real names of the functions it calls.
- DriverLab asks once before it looks for names files online. It asks GitHub for the file by the driver's build ID (and its release tag, if the driver's name has one), and keeps a file it finds, so it works offline afterwards. Settings → Driver inspector changes the choice, and **Names for all my drivers** downloads them all at once. A names file can also be loaded from a file.

**How accurate the function list is**
Measured against a Turnip build whose real function list is known (Banners-AIO v27.0.0-20261106-r2, 7,755 functions):
- without a names file: 91.4 % of the real functions found, 99.6 % of the listed functions real, 94.1 % with the exact size;
- with its names file: all functions, with real names, and about 92 % with their Mesa file and line.

**Changed**
- The APK is about 15 MB larger: it carries the decompiler engine (rizin with the rz-ghidra decompiler).
- The engine runs as its own program that Android closes first when memory runs low, and DriverLab stops it if it uses more than 35 % of the RAM, so a runaway decompile cannot get other apps closed. Very large functions are skipped and listed.

**Checked on**
- An AYANEO Pocket FIT (Snapdragon G3 Gen 3, Adreno A33 that its driver reports as Adreno 750, Android 14), the code of this release: the Banners-AIO r2 Turnip driver imported, names found online after allowing it (7,759 names), the function list with real names, decompiled code calling functions by name, the Mesa source button, removing and finding the names file again; without a names file the same function list as the accuracy test (83 s, engine up to 642 MB).
- An AYANEO Pocket FIT Elite (Snapdragon 8 Elite, Adreno 830, Android 16), an earlier build of the inspector: Make source code on the device's own Qualcomm driver (3,339 functions, 50 MB of C in about 11 minutes, 4 very large functions skipped), Overview, Functions and C code on Turnip r4-A8xx, and Compare of Turnip r4-A8xx with r4.

**Not yet seen on a device:** Make source code on this build, this build on the Pocket FIT Elite, and the Retroid Pocket Duo (Adreno 722).

**Known limits:** keep DriverLab open while Make source code runs (it does not run as a background service yet). The engine stays loaded (about 650 MB) while DriverLab sits on the inspector in the background; Android closes it first when it needs the memory.
